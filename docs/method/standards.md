# Standards

Open at the phase named. These carry the depth; `sbr.py` carries the rules
and wires each one to the phase where it applies — none of these sit
unread.

The full standards estate stays complete rather than trimmed to a minimal
core — raising the bar, not lowering it for convenience, is the point.
